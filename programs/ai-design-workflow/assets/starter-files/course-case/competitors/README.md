# Competitor pages (fictional)

Three invented competitors of the delivery app. Use them for the 20-minute competitor demo in week 2. Each file is a short stand-in for a public page. Treat them as the only sources: where a page does not say something, the answer is "unknown".

**Criteria to compare:** delivery time options, change or cancel an order, first-order experience, honesty of delivery estimates, fees and price.
